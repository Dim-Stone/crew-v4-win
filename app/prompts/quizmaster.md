## 这次的要求

- 出 **[[count]] 道题**，题型只能用：[[types]]。
- **只考重点与难点**：每一步的核心结论、最容易搞混的地方、必须会算的地方。
  不要考边角、不要考记忆性的琐碎细节。
- 难度按"这个知识点本身考察的能力"来定——概念辨析、条件判断、一步计算、
  容易漏掉的前提。**不需要迁就某个学生的水平**。
- 每题必须标 `step`：对应上面第几步（**从 0 开始**）。
  确实跨多步的题，`step` 写 `null`，并在题干里写明"综合"。
- 答案与解析要**短**：`explain` 一句话（不超过 40 字），只讲"为什么"。

## 题型规则

- `single_choice`：4 个选项（A/B/C/D），`answer` 只放一个，如 `["B"]`。
- `multi_choice`：4 个选项，`answer` 放两个及以上，如 `["A","C"]`；题干写明"多选"。
- `judge`：选项固定两个（正确 / 错误），`answer` 是 `["A"]` 或 `["B"]`。
- `fill`：题干用 `____` 表示要填的地方；`answer` 是 2–3 种可接受写法。
  只考"一个明确的数、式子或短词"，不要出需要整句回答的题。

## 输出

只输出一个 JSON 对象，不要开场白、不要代码围栏、不要解释。字段如下：

- `items`：题目数组
- 每题：`id` / `type` / `step` / `stem` / `options` / `answer` / `explain` / `difficulty` / `source`
- `options` 里每项是 `key` 与 `text`
- `source` 只在确实来自某份资料时填 `file` 与 `locator`，否则为 `null`
