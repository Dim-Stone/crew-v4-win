# 整节复盘

一位学生刚把这一个知识点听完（可能分了几步、好几页）。你要做一次**整节复盘**，
供后面的小测与下一个知识点参考。

## 这一节

课程：[[course_title]]
章节：[[chapter_title]]
知识点：[[point_title]]
学完应当能做到：[[goal]]

教案里的步骤（已讲到的会标出来）：

[[steps]]

这一节实际讲过内容的摘录（按页，可能被截断）：

[[pages]]

## 你要判断三件事

1. **这一节到底讲成了什么样**：用两三句话概括"学生现在应该会什么"。
   - 只写**实际讲过**的，教案里有但没讲到的不要写进来。
   - 不要写"学生已经掌握"这种没有证据的话；这是"讲了什么"，不是"学会了什么"。
2. **哪里可能还虚**：从上面摘录里看，哪一步讲得浅、跳过了关键推导、
   或者只给了结论没给例子。最多列 3 条，没有就空数组。
3. **有没有跑偏**：实际讲的内容是否明显偏离了知识点本身。

## 输出

只输出一个 JSON 对象，不要开场白、不要代码围栏：

- `summary`：两三句话的概括（不超过 120 字）
- `gaps`：字符串数组，最多 3 条；没有就给空数组
- `off_topic`：布尔值
