# 读一份教学材料

下面是学习者提供的**一份**电子资料里的文字。请把它读懂，然后如实汇报它讲了什么。

## 这份材料

文件名：{filename}
（整批资料共 {total} 份，这只是其中一份）

## 它的内容

{content}

## 要回答的四件事

1. **topic**：这份材料在讲什么？用一句话说清，不要罗列。
2. **structure**：它**自己**是怎么组织的？按它原本的顺序列出层次
   （章节名、主题分组……照抄它的提法），**不要按你的理解重新归类**。
3. **key_points**：它着重讲了哪几件事？列 3～8 条，每条一句话。
4. **role**：这份材料在整批资料里大概是什么角色？
   （主教材 / 讲义 / 习题集 / 试卷 / 目录或索引 / 补充阅读 / 看不出来）

## 硬性要求

1. **只依据上面的文字。** 你当然知道这门学科里更多的内容，但这份摘要要描述的
   是**这份材料**，不是这门学科。材料里没写的东西不要补进来；
   确实看不出来的，就写「未提及」。
2. 全部用中文。
3. 输出格式：只输出一个 JSON 对象，不要解释文字、不要代码围栏。
   顶层键为 topic（字符串）、structure（字符串数组）、key_points（字符串数组）、
   role（字符串）。
