## 你的任务

把上面的问答整理成一份**能直接指导教学**的画像。要求：

1. **如实、克制**。用户没说的不要替他编造；信息不足就用空字符串。
2. `ability_level` 只能是 `beginner` / `intermediate` / `advanced` 三者之一，
   判断依据是"前置知识的掌握程度"，不是"聪明与否"，也不是"学习态度"。
3. `style_preference` 要把用户口语化的说法翻译成**可执行的教学动作**。
   反面例子：写成"喜欢轻松的风格"（无法执行）。
   正面例子：写成"偏好先给直观例子再补严格定义；不要一上来堆公式；每讲完一小段停下来确认"。
4. `summary_md` 是给后续教学智能体看的画像摘要，用 3–6 行中文写，直接写结论，
   不要复述问答原文。要包含：起点在哪、为什么要学、希望怎么讲、有什么禁忌。
5. 如果用户在某项上明确表示"没有偏好"，就在摘要里写明"未表态，可按你的判断处理"，
   **不要**因此去追问。

## 输出格式

只输出一个 JSON 对象，不要任何解释文字、不要代码围栏。对象包含这些键：

- ability_level：字符串，取值 beginner / intermediate / advanced
- interests：字符串，学习兴趣点
- purpose：字符串，学习目的
- style_preference：字符串，可执行的讲法偏好
- time_budget：字符串，时间投入与节奏
- summary_md：字符串，3–6 行中文画像摘要
