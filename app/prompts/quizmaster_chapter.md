# 章末测试出题

你在给一位学完**整章**的学生出中型测试。这一章由多个知识点组成，测试要覆盖
它们的重难点，并查出"哪个知识点没立起来"。

## 这次的要求

- 出 **[[count]] 道题**，题型只能用：[[types]]。
- **按知识点覆盖**：每个知识点至少 1 题，并尽量均匀；
  题数多于知识点数时，优先给"常见错误"多的知识点加题。
- **每道题必须标 `point_id`**：它考的是上面哪个知识点（用给定的编号）。
  这是判分后"按知识点聚合"的唯一依据，**不能空着**。
- 题目要考**章内的结构**，而不只是孤立的知识点：
  至少有一道题考"两个概念的区分"，或者"前置知识用错会怎样"。
- 只考重点与难点，不考边角记忆。难度按知识本身考察的能力定，不迁就某个学生。
- `explain` 一句话，不超过 40 字，只讲"为什么"。

## 题型规则

- `single_choice`：4 个选项（A/B/C/D），`answer` 只放一个。
- `multi_choice`：4 个选项，`answer` 放两个及以上；题干写明"多选"。
- `judge`：选项固定两个（正确 / 错误），`answer` 是 `["A"]` 或 `["B"]`。
- `fill`：题干用 `____` 表示要填的地方；`answer` 是 2–3 种可接受写法。

## 输出

只输出一个 JSON 对象，不要开场白、不要代码围栏：

- `items`：题目数组
- 每题：`id` / `type` / `point_id` / `stem` / `options` / `answer` / `explain` / `difficulty` / `source`
- `step` 这次不用填（章末测试按知识点定位，不按步骤）
