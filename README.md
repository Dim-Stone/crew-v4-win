# CREW V4 · 学习工作台

一个跑在你自己电脑上的**个人学习助手**。你把一门课的目标和手头的资料交给它，
它把课程拆成章与知识点、写出讲授提纲，然后按你的提问实时讲授和答疑。

**所有东西都在本机**：课程、讲义、待办、记事都存在这个文件夹里，只有调用模型
的时候才联网。

---

## 三步开始

1. 双击 **`启动.bat`**
2. 第一次打开会提示"还差一步：填一个 API 密钥"——点"去设置"，
   把密钥粘贴进去，点 **保存并测试**（密钥在 <https://platform.deepseek.com> 申请）
3. 看到"连接成功"就回到课程页，新建一门课

`.env` 由程序自己创建和修改，**不需要你手动编辑**。

这台电脑**不需要装任何东西**——Python、依赖、公式渲染器都在这个文件夹里，
第一节课之前也不需要联网。

> **没有密钥也能先打开看看**：课程、讲义、待办、记事都正常使用，只有
> "摸底解析、生成大纲、讲课"这三个要用模型的动作会提示尚未配置。

---

## 它是怎么工作的

建一门课的时候它会先问你几个问题（这门课要靠什么资料、想学到什么程度、
有没有相关基础），然后：

| 阶段 | 它在做什么 |
| --- | --- |
| 摸底 | 读你给的资料，形成对你当前水平的判断 |
| 拆课 | 把课程拆成章、章拆成知识点，并给出先后顺序 |
| 备课 | 逐个知识点写出讲授提纲 |
| 讲课 | 按你的提问实时讲授、答疑；讲过的内容它会记住，后面接着讲 |

**资料可以不放**，那就按它自己的知识讲。放了资料（`.txt` `.md` `.pdf`
`.pptx` `.docx`）它会优先依照资料讲——讲义里会标出依据来自哪一份、第几页，
所以你可以随时核对。

## 界面里的几块

- **工作台** —— 最上面是"今天"：日期可以逐日、逐月、逐年调整，下面是一天的
  待办和记事，都按日期分开保存。再往下是课程卡片，一眼能看到每门课讲到哪了。
- **新建课程** —— 五步向导，在一页里走完。
- **课程页** —— 左边是章与知识点，右边是对话。选中一个知识点就能开讲，
  也可以直接把问题打进去。
- **讲义** —— 每一轮讲过的内容都会自动落成文件，可以回头翻。
- **设置** —— 密钥与模型；界面外观（字号、行宽、行间距、密度、主题）。

## 你的东西存在哪

都在**这个文件夹**里，跟着它走：

```
instance\    数据库（课程、待办、记事）、日志、界面偏好
notes\       每一轮授课生成的讲义
.env          你的密钥
```

所以想备份就直接把这个文件夹拷走；换一台电脑，也是把它拷过去。
删掉 `instance\` 与 `notes\` 之后会重新生成——但里面的课程和讲义也就真没了。

## 出问题的时候

- **窗口一闪而过，或者打不开** → 打开 `instance\v4_win.log`，最新的在最下面。
- **提示没有 `.env`** → 回到上面"三步开始"的第 1–2 步。
- **提示开不了自己的窗口，改用浏览器打开** → 那个黑框**不要关**，用完之后在
  里面按 Ctrl+C。想要回原生窗口，装一下 Microsoft Edge WebView2 运行时即可。
- **讲课失败** → 多半是密钥或模型名的问题。去 **设置 → 环境配置** 看一眼，
  页面上会显示当前用的是哪个模型。

## 关于

CREW 是一套个人学习工具。这个便携版把运行环境全部打包在一起，方便拷给别人
试用：解压、填密钥、就能开始。当前版本见界面里的 **设置 → 关于**。
